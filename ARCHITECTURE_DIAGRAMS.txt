                        REQUEST FLOW SEQUENCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

USER REQUEST
    │
    │  POST /api/generate
    │  { prompt, duration, model }
    │
    ▼
VALIDATE INPUT
    │
    ├─ Prompt: 10-500 chars ✓
    ├─ Duration: 5-30 seconds ✓
    ├─ Model: [small|medium|large] ✓
    │
    └─ ✓ Valid
    │
    ▼
CREATE PREDICTION (Replicate API)
    │
    │  POST https://api.replicate.com/v1/predictions
    │  { version, input: {prompt, duration} }
    │
    ▼
POLL FOR COMPLETION
    │
    ├─ Status: processing → exponential backoff
    ├─ Check every 1s, 1.5s, 2.25s, etc (max 10s)
    ├─ Max wait: 5 minutes
    ├─ Max attempts: 120
    │
    └─ Status: succeeded ✓
    │
    ▼
DOWNLOAD AUDIO FILE
    │
    │  GET audioUrl
    │  Stream → /data/generations/{id}.wav
    │  Max size: 50MB
    │
    ▼
SAVE METADATA
    │
    │  Update /data/metadata.json
    │  {
    │    "id": "...",
    │    "prompt": "...",
    │    "status": "completed",
    │    "localFile": "{id}.wav",
    │    "createdAt": "..."
    │  }
    │
    ▼
RETURN RESPONSE
    │
    │  {
    │    "success": true,
    │    "data": {
    │      "id": "...",
    │      "status": "completed",
    │      "prompt": "...",
    │      "audioUrl": "...",
    │      "createdAt": "..."
    │    }
    │  }
    │
    ▼
USER RECEIVES RESPONSE
    │
    ├─ Via API: JSON response
    └─ Via CLI: Colored output + audio saved

                          ERROR HANDLING FLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ERROR DETECTED
    │
    ├─ VALIDATION_ERROR (400)
    │  └─ Invalid prompt/duration/model
    │
    ├─ AUTH_ERROR (401)
    │  └─ Invalid Replicate API token
    │
    ├─ RATE_LIMIT_ERROR (429)
    │  └─ Replicate quota exceeded
    │
    ├─ TIMEOUT_ERROR (504)
    │  └─ Generation took > 5 minutes
    │
    ├─ NOT_FOUND (404)
    │  └─ Generation ID doesn't exist
    │
    └─ GENERATION_ERROR (500)
       └─ Replicate prediction failed
    │
    ▼
LOG ERROR
    │
    ├─ Error code
    ├─ Error message
    ├─ Request details
    └─ Timestamp
    │
    ▼
CREATE ERROR RESPONSE
    │
    │  {
    │    "success": false,
    │    "error": {
    │      "code": "ERROR_CODE",
    │      "message": "Human-readable message",
    │      "details": ["additional info"]
    │    }
    │  }
    │
    ▼
RETURN WITH APPROPRIATE HTTP STATUS
    │
    └─ Client handles error gracefully

PATTERN A: UT QUEANT LAXIS (Vocal Analysis)
────────────────────────────────────────────

Vocal Audio File
    │
    ▼
ANALYZE (Ut Queant Laxis)
    │
    ├─ Extract: pitch, tempo, timbre, energy
    ├─ Generate description: "ambient electronic 70bpm warm pads"
    │
    ▼
GENERATE MUSIC (MusicGen Wrapper)
    │
    ├─ POST /generate { prompt }
    │
    ▼
DOWNLOAD & INTEGRATE
    │
    ├─ Audio saved locally
    ├─ Aligned with vocal timing
    │
    ▼
OUTPUT: Combined vocal + generated music

    ▼
DOWNLOAD ALL TRACKS

    │

    │
    ▼

  Small model:    30-45 seconds
  Medium model:   45-60 seconds
  Large model:    60-90 seconds

STORAGE PER GENERATION
  Audio file:     ~2-3MB (10 seconds)
  Metadata:       ~1KB
  Total per gen:  ~2-3MB

API RESPONSE TIMES
  Validation:     <10ms
  List/Filter:    <100ms
  Download:       Network dependent
  Health check:   <5ms

CONCURRENT LIMITS
  Replicate API:  Check account limits
  Rate limit:     10 requests/minute (configurable)
  Storage:        Disk capacity
  Memory:         Node.js standard
